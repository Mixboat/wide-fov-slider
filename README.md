# Wide FOV Slider storage page

This repo hosts the small page the [Wide FOV Slider](https://gamebanana.com/mods/724244) Deadlock mod uses to remember your slider value.

The mod loads https://mixboat.github.io/wide-fov-slider/ in a hidden in-game browser panel. The page keeps a few numbers (your Wide FOV value and some status timestamps) in its own browser localStorage on your PC. It sends nothing anywhere and loads nothing else.
